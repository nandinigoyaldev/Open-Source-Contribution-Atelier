## 💖 Our Emotional Journey: From Zero to Open Source Heroes

> _"Open source is never just about code; it is about the friendships forged across timezones, the late-night debug sessions, the patience of mentors, and the boundless courage of first-time contributors taking their very first leap into git commit history."_

When this season began, our mission was simple yet ambitious: to create an accessible, neobrutalist, gamified atelier where anyone—regardless of background—could learn git workflows, master full-stack development, and transition into fearless open-source contributors.

What happened next exceeded all expectations:

- **Hundreds of Pull Requests reviewed & merged** across full-stack architectures, interactive Git sandboxes, accessibility linter challenges, and neobrutalist UI components.
- **Dozens of first-time open-source contributors** made their very first git commits right here in our repository, overcoming imposter syndrome and blossoming into confident software engineers.
- **A vibrant, supportive community** flourished where maintainers and contributors lifted each other up with constructive feedback, high-fives, and shared knowledge.

To every contributor who opened an issue, refactored a module, designed a card, fixed a typo, or shared words of encouragement: **This victory belongs to you. You made this atelier a home.**

## ❄️ NSoC '26 Mandatory Labels & Points System

All tasks under **Nexus Spring / Winter of Code 2026** use the following mandatory tagging and scoring structure:

| Label | Description | Points Awarded | Scope Examples |
|:---:|---|:---:|---|
| **`NSOC26`** | **Compulsory Program Label** | — | Must be present on all participating issues & PRs |
| **`LEVEL1`** | **Beginner Tier** | **10 Points** | Documentation updates, typo/link fixes, simple UI tweaks, basic unit tests |
| **`LEVEL2`** | **Intermediate Tier** | **25 Points** | Feature additions, API endpoint extensions, new reusable components, bug fixes |
| **`LEVEL3`** | **Advanced Tier** | **50 Points** | Core architecture refactoring, complex modules, security hardening, full-stack pipelines |

> 💡 **Automated Scoring**: When your Pull Request linking a `NSOC26` issue with `Fixes #<number>` is merged, our bot calculates your points and awards your commemorative NSoC '26 contributor badge!

## 🚀 How to Contribute Post-Season (Evergreen Guidelines)

Open-Source Contribution Atelier is permanently open for contributions year-round! Here is how you can jump in:

1. Browse open issues tagged with [`good first issue`](https://github.com/nandinigoyaldev/Open-Source-Contribution-Atelier/labels/good%20first%20issue) or [`help wanted`](https://github.com/nandinigoyaldev/Open-Source-Contribution-Atelier/labels/help%20wanted).
2. Comment `/claim` or `/assign` on an unassigned issue to have our bot assign it to you.
3. Fork the repository, create a descriptive feature branch (`feature/amazing-feature`), and write clean, tested code.
4. Submit your Pull Request linking the issue with `Fixes #issue_number`.
5. Once reviewed and merged, you will be celebrated in the Hall of Fame and earn project contributor badges! 🎉
